# Namecheap Stellar Shared Hosting - Next.js Deployment

This package is designed to run as a **Node.js application** through cPanel's **Setup Node.js App** feature. Do not deploy it like a PHP website by only copying files into `public_html`.

## 1. Back up the existing website

Before replacing the current website, download a backup of the current `public_html` files.

## 2. Upload the project ZIP

In cPanel File Manager, create an application folder outside `public_html`, for example:

```text
/home/CPANEL_USERNAME/nexasmc-nextjs
```

Upload and extract this project there.

The application root should directly contain:

```text
app/
components/
content/
lib/
public/
storage/
package.json
next.config.mjs
server.js
```

Do not leave the project inside an extra nested ZIP folder.

## 3. Create the Node.js app

Open:

```text
cPanel
-> Software
-> Setup Node.js App
-> Create Application
```

Use:

```text
Node.js version: 22.x
Application mode: Production
Application root: nexasmc-nextjs
Application URL: your nexasmc.com domain/root URL
Application startup file: server.js
```

Create the application.

## 4. Add environment variables

Inside the Node.js application settings add:

```text
NEXA_SMTP_HOST=server390.web-hosting.com
NEXA_SMTP_PORT=465
NEXA_SMTP_SECURE=true
NEXA_SMTP_USERNAME=info@nexasmc.com
NEXA_SMTP_PASSWORD=YOUR_REAL_MAILBOX_PASSWORD
NEXA_SMTP_FROM_EMAIL=info@nexasmc.com
NEXA_SMTP_FROM_NAME=nexaSMC Website
NEXA_CONTACT_TO_EMAIL=info@nexasmc.com
NEXT_PUBLIC_SITE_URL=https://nexasmc.com
```

Do not put the mailbox password in source code or send it in chat.

For email testing only, you can temporarily use:

```text
NEXA_CONTACT_TO_EMAIL=your-test-gmail@gmail.com
```

## 5. Install NPM packages

Use cPanel's **Run NPM Install** button if available.

If using Terminal, cPanel normally shows a command to enter the application's Node virtual environment. Run that command first, then:

```bash
cd ~/nexasmc-nextjs
npm install
```

## 6. Build Next.js

In the same Node environment:

```bash
npm run build
```

A successful build creates the `.next` directory.

## 7. Visitor counter permissions

The Node process must be able to write to:

```text
storage/visitor-count.json
```

Normally files extracted under your cPanel account are already writable by your Node application. If the counter gives a permission error, use:

```bash
chmod 775 storage
chmod 664 storage/visitor-count.json
```

Do not expose the `storage` directory through `public/`.

## 8. Restart the Node application

Return to:

```text
Setup Node.js App
-> nexaSMC application
-> Restart
```

## 9. Test the website

Open:

```text
https://nexasmc.com
```

Check all sections and responsive navigation.

Visitor counter test:

```text
https://nexasmc.com/api/visitor-counter
```

Expected format:

```json
{"ok":true,"count":1}
```

Refreshing from the same browser on the same UTC day should not add another visitor.

## 10. Test contact email

Submit the website Contact Form.

For the first test it is useful to set:

```text
NEXA_CONTACT_TO_EMAIL=your-test-gmail@gmail.com
```

After the test succeeds, change it back to:

```text
NEXA_CONTACT_TO_EMAIL=info@nexasmc.com
```

If sending fails, check the Node application error log and:

```text
storage/contact-mail-errors.log
```

Confirmed cPanel SMTP settings used by this project are:

```text
Outgoing Server: server390.web-hosting.com
SMTP Port: 465
Security: SSL/TLS
SMTP Authentication: Required
Username: info@nexasmc.com
```

## 11. Future updates

After uploading changed code/content:

```bash
npm install
npm run build
```

Then restart the application in cPanel.

If only static content in `content/` changes, a rebuild is still required because the pages are generated by Next.js.
